# Returned review findings

A separately selected planning or specification-return session reads the applicable full committed report before affected setup/edits. It verifies feature, reviewed candidate, disposition and report integrity, then records required corrections, applicable resolution evidence or precise unresolved input in existing feature artifacts. Required findings remain obligations at any priority; genuinely optional advice is voluntary with concise adopted/declined reasons. These are prescribed rules, not runtime acceptance proof. (S012)

Planning return preserves approved meaning, task identities and completion evidence, performs separate repair/fresh read-only analysis and stops for full-plan review. Specification escalation uses ordinary clarification/revision on the same feature, retains authority across genuine waits and returns to human whole-spec review; no fresh drafting or inferred approval. Standalone callers provide equivalent explicit current evidence without Diagram. [Workflow handoffs](./workflow-handoffs.md) preserve these execution boundaries. (S012)
