# Local metrics component boundary

The shared controller package owns standard-library collection around declared native agent turns. Local wall-clock timing produces one JSON record per completed turn under `~/.farmboy/metrics/`; separate files and no-clobber publication support concurrent workflows without a shared append file or lock. (S003)

A metrics failure warns while preserving the original dispatch result and human gates. Model and effort are passive observations of explicit values in the exact matching project agent TOML; the helper neither resolves nor overrides native configuration. (S003)

The maintainer-only `farmboy-metrics-report` source skill consolidates a fixed snapshot into an XLSX workbook and is excluded from consumer packages. The generic source has no Diagram runtime service dependency; Diagram adoption remains a separately versioned adapter boundary. These architecture contracts do not establish publication, consumer adoption or acceptance. (S003)

[Bundle and workflow model](./bundle-and-workflow-model.md) places these components within FarmBoy's generic source boundary. (S003)
