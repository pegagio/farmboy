# Project context pointers

Consult `docs/direction.md` when the task needs direction, goals, scope or roadmap context; routine loading is unnecessary. Separate agreed direction from recommendations and open questions. (S003)

The declared roadmap convention is `flow-roadmap` with `.specify/memory/roadmap.md` as the record of known planned features. The declared wiki convention is `flow-wiki` with `wiki/` as the project knowledge store and `$speckit-flow-wiki-query` for project-context questions. These conventions do not establish that planned work is implemented. (S003)

Keep task work within the repository and current worktree unless explicitly directed otherwise. Additional access needs its own explicit authorization; permission for one location is not permission for others. Use only pegagio/Pegagio for the owner and portable home paths in repository artifacts. (S003)

The constitution governs development; see [prescribed workflow authority](./workflow-authority.md). Farmboy retains reusable execution, while Diagram retains coordination authority in its own project. (S003)
