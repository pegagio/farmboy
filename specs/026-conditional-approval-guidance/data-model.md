| Existing value | Required meaning |
| --- | --- |
| Historical spec approval / review conditions | Actual applicable decision and its limits; not execution permission inferred from flags |

| Planning offer request | Action-allowed current identity/revision/approval/assessment facts; read-only and no ownership |
